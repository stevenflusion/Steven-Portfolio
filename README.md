# Steven's 3D Portfolio

A modern 3D portfolio built with React, Three.js, and Tailwind CSS. Features interactive 3D elements
and bilingual support (English/Spanish).

## Features

- **3D Interactive Elements**: Built with React Three Fiber and Three.js
- **Bilingual Support**: Toggle between English and Spanish
- **Responsive Design**: Works on desktop and mobile
- **Smooth Animations**: Powered by Framer Motion
- **Modern Tech Stack**: React 18, TypeScript, Vite, Tailwind CSS

## Getting Started

### Prerequisites

- Node.js 18+
- pnpm (recommended) or npm

### Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```

### Build

```bash
# Build for production
pnpm build

# Preview production build
pnpm preview
```

## Tech Stack

- **Frontend**: React 18, TypeScript
- **3D**: Three.js, React Three Fiber, React Three Drei
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, Maath
- **Routing**: React Router DOM
- **Build Tool**: Vite

## Project Structure
